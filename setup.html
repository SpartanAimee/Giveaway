Giveaway setup

Fill in your details and every step below fills itself in, ready to copy and paste. Tick each one off as you go.

Six steps

Do them in order. Each one shows what to copy as soon as it has the details it needs.

1

Database

Supabase > SQL Editor

Copy the database code, open the SQL editor, paste it in and click Run.

2

Twitch app

dev.twitch.tv > Register Your Application

Make an app with these OAuth Redirect URLs. Category: Website Integration. Client Type: Confidential.

3

config.js

Your GitHub copy > docs/config.js

Copy this, open config.js on GitHub, click the pencil, replace everything and click Commit changes.

4

Supabase function

Edge Functions > Deploy a new function > Via Editor

Name it web-giveaway, paste the code and click Deploy.

5

Secrets

Edge Functions > Secrets

Add these three, then click Save.

6

Log in

Your control page

Give GitHub a minute after committing config.js. Then log in, click Connect Twitch and Test chat. Your OBS overlay link is there too.
